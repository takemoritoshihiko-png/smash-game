# SMASH GAME — ULTIMATE BRAWL

ブラウザで動く 2D対戦アクション。キャラ29体・ステージ5つ・CPU対戦・オンライン対戦つき。

**遊ぶ:** https://takemoritoshihiko-png.github.io/smash-game/

ローカルで遊ぶときは `index.html` をブラウザで開くだけ（サーバー不要）。

## 操作

操作は1種類だけ。オンライン対戦の相手も、自分のPCで同じキーを使う。
（※ 1台のキーボードで2人対戦するモードは今は無い。コード上に2P用のキー
WASD/U/I/O/P が残っているが、どのモードからも到達しないので動かない）

| | キー |
|---|---|
| 移動 | ← → |
| しゃがみ | ↓ |
| ジャンプ（2段可） | ↑ |
| 攻撃 | Z |
| 強攻撃・投げ | X |
| コンボフィニッシャー（15コンボ以上） | C |
| ガード | Shift |

- **スマッシュ攻撃**：同じ方向を素早く2回入力 → Z（例：→→＋Z で横スマッシュ）
- **必殺技**：D 長押し（ゲージ100%のとき。専用の動画演出が入る）
- **復帰技**：↑ + X（空中で1回だけ）
- **掴み・投げ**：A + 方向キー
- **エアダッシュ**：空中で 方向 + D
- F3（またはバトル中にH）でヒットボックス表示のON/OFF

ゲーム内の **H キー（HOW TO PLAY）** でも操作を確認できます。

## キャラクター選択

- **矢印キー（← → ↑ ↓）** でカーソル移動（上下は同じ列の中で ぐるっと回る）。
  列数は `SELECT_COLS`（index.html）。上下の歩幅も これ
- CPU／2P側の カーソルは **A D W S**
- **I キー** で **CHARACTER DETAILS**（キャラ詳細画面）。画面の右下に ボタンが 光っている
  - 詳細画面は 3ページ。**Z キー**（または 1 / 2 / 3）で 切りかえ
    1. **MOVES** … 弱・強・スマッシュ・必殺・復帰・掴み・エアダッシュ・必殺技・フィニッシャーの ダメージ／発生／ノックバック
    2. **COMMANDS** … コマンド技3つ（入力・ダメージ・発生・飛び道具かどうか）
    3. **COMBOS** … `COMBO_ROUTES` の コンボ（ルート・ダメージ帯・ヒット数・難易度★・撃墜コンボかどうか）
  - 詳細画面でも **← → ↑ ↓** で 別のキャラに 切りかえられる

## 画面

- **ENTER** ゲーム開始（CPU対戦／BOSS RUSH／TRAINING）
- **O** オンライン対戦
- **C** コンボリスト
- **T** 戦績

## オンライン対戦

PeerJS（P2P）を使っています。**サーバーを立てる必要はありません。**

1. 両方のプレイヤーが公開URLを開く
2. タイトルで **O** を押す
3. 片方が「ホスト」を選ぶと ID が表示される
4. もう片方が「ゲスト」を選んで、その ID を入力して接続

※ 以前の README にあった `node server.js` での LAN対戦は、もう使っていません（server.js も ありません）。

## バランス調整

`BALANCE_TWEAK`（index.html）で キャラ別に 倍率を かけている。**ここの数字だけ いじれば 調整できる。**

```js
const BALANCE_TWEAK = {
  12: { dmg: 0.88, kb: 0.88 },   // dmg=ダメージ倍率 / kb=吹っ飛ばし倍率
  22: { dmg: 1.10, frames: 0.86 }, // frames=発生と硬直の倍率（小さいほど速い）
};
```

調整の 決め方（2026-11）:
- 30キャラの「平均ダメージ・技の効率(ダメージ÷全体フレーム)・リーチ・
  ノックバック・体重・移動速度」を 数値化し、中央値と 比べて 点数化
- 中央値から 離れすぎている キャラだけ 10%前後 寄せる
- **リーチや 体重など「持ち味」は 残す**。Long の 長い槍、Don の 重さ、
  Onpa の 吹っ飛ばしは そのまま
- 結果: 強さの 幅 0.644 → 0.457（約3割 縮小）

## 試合のルール

- 相手のストックを 全部 奪えば 勝ち（WINNER）
- **時間切れ（0:00）は 引き分け**。ストック差・ダメージ差に 関係なく **TIME UP!! / DRAW** になる
  - 変えたいときは `battleTimer <= 0` の所（`isDraw = true` を 書いている あたり）

## スマブラ寄せの 仕組み（2026-11 追加）

| 仕組み | 定数 | 中身 |
|---|---|---|
| ヒットストップ | `HITSTOP_SCALE` | スマブラと同じ `ダメージ×0.65+6` フレーム（上限30F）。止まっている間 両者が 震える（`hitVib`）|
| 小ジャンプ | `SHORT_HOP_V` | ジャンプキーを すぐ はなすと 上昇を 打ち切る。高さは 大ジャンプの 約50%。CPUは 対象外（復帰できなくなるため）|
| 撃墜演出 | - | 上に 飛ぶと 星に なる（Star KO）／下に 落ちると 画面の下が 光る／横は 従来の 爆発 |
| ラグ | `RAGE_START` `RAGE_MAX` `RAGE_MULT` | 自分の%が 高いほど 吹っ飛ばし力UP。35%から 効き、150%で 1.1倍 |

## 必殺技の動画

`images/ultimates/*.mp4`（22本・1本 5〜19MB・合計146MB）。重いので 読み方を 工夫している。

- **ゲージが 100% に なった時点で 裏で 読み込む**（`prefetchUltimateVideo`）。発動してから 読むと 真っ黒な 画面が 出る
- **再生できる 状態に なるまで 画面に 出さない**。1.2秒 待って ダメなら 動画は あきらめて 先へ進む
- **動画が 無いキャラ（7体）は 待たずに 即スキップ**（`video.error` を 見る）
- **再生が 1.5秒 進まなければ 打ち切る**（回線が 詰まったときに 固まらないように）
- **動画が 出ている間は ゲーム画面を 描かない**（`ultimateVideoShowing`）。同時に 走ると カクつく
- **どれかの キーか クリックで 飛ばせる**
- 一度 読んだ 動画は 使いまわす（同じ試合で 2回目は 即再生）

※ 根本的に 軽くするには mp4 を 再エンコードする 必要がある（ffmpeg が 要る）

## 開発メモ

- **画像は WebP**。`images/` に PNG を足したときは WebP に変換してから参照すること（元は109MBのPNGで、起動が重かった）
- **スプライトは遅延ロード**。`lazySprites()` が「最初に描こうとした瞬間」に読み込むので、起動時に全キャラ分を読まない。新しいキャラを足すときも同じ書き方にする
- **グラデーションは `cachedLinGrad()`** を使う。`ctx.createLinearGradient()` を毎フレーム呼ぶと無駄になる
- BGM は `preload='none'`。再生するまでダウンロードしない
- **打撃音**（`HIT_VOICES` と `playHitSound(type, power, charIdx)`、`playKOSE()`）
  - **技ごとに別の音**。弱・横強・上強・下強・空中・メテオ・ダッシュ・飛び道具・強・スマッシュ・必殺・コマンドの12種類を `HIT_VOICES` の表で作り分けている
  - 1発の音は **①アタック（高域ノイズ）＋②ボディ（音程が急降下）＋③サブ（低音）**（＋空気・金属）
  - 歪み（`satCurve()`）とコンプを通してから出す。サイン波だけだと「ピコッ」と軽くなる
  - `power` にノックバック量、`charIdx` に攻撃したキャラを渡す。**重いキャラほど音程が低い**
  - 連打しても同じ音にならないよう、毎回 ±7% だけ音程をずらしている
  - **音を変えたいときは `HIT_VOICES` の数字だけ**いじればよい（他は触らなくていい）
- **同じ技の連発ハメ防止**（`REP_WINDOW` / `REP_FLOOR` と `applyHit` 内の `repEscalate`）
  - 同じ技を 0.75秒以内に 3発・4発と 連続で当てると、ノックバックに下限がかかって 相手が だんだん離れる
  - そのとき「コンボ補正（KB×0.7^コンボ数）」を かけない。この補正が かかり続けるせいで 弱攻撃連打が ハメになっていた
  - 技を 変えれば カウントはリセット。いろんな技を混ぜるコンボは 今までどおり つながる
  - 強さを変えたいときは `REP_FLOOR = [3.2, 4.6, 6.0]`（3発目・4発目・5発目以降の下限）をいじる
