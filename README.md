# SMASH GAME — ULTIMATE BRAWL

ブラウザで動く 2D対戦アクション。キャラ29体・ステージ5つ・CPU対戦・オンライン対戦つき。

**遊ぶ:** https://takemoritoshihiko-png.github.io/smash-game/

ローカルで遊ぶときは `index.html` をブラウザで開くだけ（サーバー不要）。

## 操作

操作は1種類だけ。オンライン対戦の相手も、自分のPCで同じキーを使う。
（※ 1台のキーボードで2人対戦するモードは今は無い。コード上に2P用のキー
WASD/U/I/O/P が残っているが、どのモードからも到達しないので動かない）

| | キー |
|---|---|
| 移動 | ← → |
| しゃがみ | ↓ |
| ジャンプ（2段可） | ↑ |
| 攻撃 | Z |
| 強攻撃・投げ | X |
| コンボフィニッシャー（15コンボ以上） | C |
| ガード | Shift |

- **スマッシュ攻撃**：同じ方向を素早く2回入力 → Z（例：→→＋Z で横スマッシュ）
- **必殺技**：D 長押し（ゲージ100%のとき。専用の動画演出が入る）
- **復帰技**：↑ + X（空中で1回だけ）
- **掴み・投げ**：A + 方向キー
- **エアダッシュ**：空中で 方向 + D
- F3（またはバトル中にH）でヒットボックス表示のON/OFF

ゲーム内の **H キー（HOW TO PLAY）** でも操作を確認できます。

## 画面

- **ENTER** ゲーム開始（CPU対戦／BOSS RUSH／TRAINING）
- **O** オンライン対戦
- **C** コンボリスト
- **T** 戦績

## オンライン対戦

PeerJS（P2P）を使っています。**サーバーを立てる必要はありません。**

1. 両方のプレイヤーが公開URLを開く
2. タイトルで **O** を押す
3. 片方が「ホスト」を選ぶと ID が表示される
4. もう片方が「ゲスト」を選んで、その ID を入力して接続

※ 以前の README にあった `node server.js` での LAN対戦は、もう使っていません（server.js も ありません）。

## 開発メモ

- **画像は WebP**。`images/` に PNG を足したときは WebP に変換してから参照すること（元は109MBのPNGで、起動が重かった）
- **スプライトは遅延ロード**。`lazySprites()` が「最初に描こうとした瞬間」に読み込むので、起動時に全キャラ分を読まない。新しいキャラを足すときも同じ書き方にする
- **グラデーションは `cachedLinGrad()`** を使う。`ctx.createLinearGradient()` を毎フレーム呼ぶと無駄になる
- BGM は `preload='none'`。再生するまでダウンロードしない
